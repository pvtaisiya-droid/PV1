Независимые функции ручного учёта, публикации, уведомлений, диагностики и
локального backup/restore реализованы без ожидания внешних документов.
Для закрытия пользовательской приёмки ФН должен пройти один реальный рабочий
маршрут на синтетическом случае: подготовка → решение о резерве → фактическая
ручная подача (в локальной имитации) → результат → проверка/исправление публикации
→ разбор задачи. IT отдельно принимает носитель/секреты/наблюдение и аварийный
порядок; межсистемную совместимость подтверждает только испытание с РЗН.
