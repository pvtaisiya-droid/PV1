# Импорт договоров PV1

Импорт соответствует быстрому сценарию «Новый партнёр». GPT извлекает только данные, которые можно проверить и скорректировать в предпросмотре перед сохранением.

| Раздел | Поля |
|---|---|
| Партнёр | Код, название, статус, частота сверки |
| Информация для бухгалтерии | Юрлицо для счета, ИНН, КПП, контакт для счетов, специальный e-mail для счетов, комментарий о порядке направления счетов |
| Контактные лица | Фамилия, имя, отчество, должность, тип и статус контакта, актуальность, email, мобильный/рабочий телефон, добавочный номер, сайт, адрес, участие в сверке, комментарии |
| Договор или ДС | Тип, основной договор, номер, дата, действителен до |
| Препараты | Торговое наименование, действующее вещество RU/EN и ATC, лекарственная форма RU/EN и группы RU/EN, дозировка, комментарий |
| Услуги и цены | Договор, услуга, единица, цена, комментарий |

Для действующих веществ, лекарственных форм и услуг сначала выполняется сопоставление со справочниками из `contract_import_reference_values.json`. Если совпадение не найдено, GPT передаёт извлечённые значения и добавляет вопрос в `manual_review`; пользователь подтверждает создание новой справочной записи в предпросмотре.

Отсутствующие сведения не придумываются: значение остаётся `null`, а в `manual_review` добавляется указание для ручного заполнения. Для счетов извлекается только специальный бухгалтерский e-mail — общий адрес организации не используется вместо него. Контакт из пункта о выставлении или направлении счетов имеет приоритет как контакт для счетов, даже если в другом приложении он назван менеджером проекта. Иные реквизиты сторон, обязанности ФН, сроки передачи сообщений, условия расторжения/продления, НДС и регистрационные статусы не входят в новый сценарий и в интерфейсе не показываются.

Если PV1 находит существующего партнёра, пользователь должен выбрать его карточку и отдельно подтвердить, что договор относится именно к нему. После подтверждения отсутствующая или изменённая информация для бухгалтерии добавляется в карточку партнёра. Уже существующие реквизиты, договоры, контакты, препараты, связи и тарифы повторно не создаются: найденные дубли показываются в предпросмотре и в итоговом отчёте импорта.

Для существующего партнёра бухгалтерские реквизиты можно сохранить отдельно кнопкой «Сохранить только информацию для бухгалтерии». Эта операция не изменяет договор, контакты, препараты и тарифы.

Контакт для счетов одновременно сохраняется в таблицу контактных лиц с назначением «Бухгалтерия». Совпадение определяется прежде всего по e-mail внутри выбранного партнёра. Если контакт уже существует, новая строка не создаётся: к существующему контакту добавляется дополнительное бухгалтерское назначение, а его прежнее назначение сохраняется.

Контакты ООО «АРС», сотрудников Исполнителя и адреса домена `pharmrussia.com` автоматически исключаются из списка контактов партнёра и никогда не сохраняются при импорте договора.

Кнопка «Скачать пакет для GPT» формирует единый ZIP с актуальным промптом, схемой, примером и текущими справочниками базы. Архив загружается в GPT вместе с договором; полученный JSON затем загружается на страницу импорта PV1.
