# Вход в АИС РЗН для партнёра

1. Откройте `C:\Codex\PV1\open-ais-rzn.cmd` двойным щелчком.
2. Выберите партнёра из базы PV1 и привычный браузер.
3. Проверьте адрес входа. По умолчанию указан `http://external.roszdravnadzor.ru/`,
   на который ведёт [официальная страница системы «Фармаконадзор»](https://www.roszdravnadzor.gov.ru/services/npr_ais).
   Если вы используете другую страницу АИС, вставьте её HTTPS-адрес.
   Этот адрес АИС работает по HTTP: соединение не шифруется. HTTPS для него
   при проверке 21 сентября 2026 года завершался ошибкой соединения.
4. Нажмите **Открыть АИС**. При первом открытии войдите с логином и паролем
   выбранного партнёра и подтвердите сохранение пароля в браузере.
5. Нажмите **Создать ярлык на рабочем столе**. Затем можно открывать АИС
   для этого партнёра непосредственно через ярлык.

Запускатель открывает отдельный постоянный профиль для каждой пары
«партнёр + браузер». При первом входе именно вы связываете его с учётной записью
партнёра в АИС. Запускатель не проверяет, под какой учётной записью выполнен вход.
При повторном открытии используется тот же профиль: браузер может сохранить
сеанс или предложить сохранённый пароль. Если АИС требует нажать «Войти»,
ввести капчу или код подтверждения, сделайте это самостоятельно.

При смене браузера пароль необходимо сохранить заново. Для каждого браузера
создаётся собственный ярлык. Название партнёра можно менять в PV1:
профиль привязан к постоянному идентификатору записи в базе.

Если ярлык был создан первой версией запускателя с адресом `https://external.roszdravnadzor.ru/`,
откройте обновлённый запускатель и нажмите **Создать ярлык на рабочем столе**
для того же партнёра и браузера. Адрес в ярлыке обновится; профиль останется прежним.

Если Chrome не предложил сохранить пароль, воспользуйтесь
[менеджером паролей Chrome](https://support.google.com/chrome/answer/95606?hl=ru)
в открывшемся окне партнёра и добавьте запись для страницы входа.
Разделение данных по профилям описано в
[справке Chrome](https://support.google.com/chrome/answer/2364824?hl=ru).

## Где хранятся данные

- Настройки запуска: `%LOCALAPPDATA%\PV1\AIS-RZN\settings.json`.
- Профили браузера: `%LOCALAPPDATA%\PV1\AIS-RZN\profiles\`.
- Пароли и сеансы сохраняет браузер внутри своего профиля. Запускатель не
  запрашивает пароли, не переносит их из обычного профиля и не записывает в PV1.

Не удаляйте папку профилей, если хотите сохранить пароли и сеансы.
Для запуска не требуется работающий сервер PV1; база партнёров читается без изменений.
Используются установленный браузер и Python из `.venv`, без дополнительных пакетов.

Для другой SQLite-базы:

```powershell
.\.venv\Scripts\python.exe .\tools\ais_rzn_launcher.py --database C:\path\pv_system.db
```
