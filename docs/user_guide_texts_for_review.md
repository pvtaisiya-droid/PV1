# Тексты интерфейсного помощника

Заполните колонку «Новая редакция». Идентификаторы менять не нужно: по ним обновлённые тексты будут перенесены обратно в интерфейс. Если текущий текст нужно удалить полностью, напишите `УДАЛИТЬ`.

## Общие шаги помощника

Эти формулировки используются автоматически на разных страницах в зависимости от того, какие элементы там есть.

| ID | Где показывается | Текущий текст | Новая редакция |
|---|---|---|---|
| step.overview.title | Заголовок страницы | Сначала сориентируйтесь | |
| step.overview.body | Заголовок страницы | Проверьте название страницы и краткую сводку. Так вы убедитесь, что работаете в нужном разделе. | |
| step.tabs.title | Вкладки | Выберите рабочий раздел | |
| step.tabs.body | Вкладки | Переключайтесь между вкладками по этапам задачи. Данные сохраняются только после нажатия кнопки сохранения внутри выбранной вкладки. | |
| step.filters.title | Фильтры и поиск | Найдите нужные записи | |
| step.filters.body | Фильтры и поиск | Задайте один или несколько фильтров и нажмите кнопку поиска. Чтобы снова увидеть все записи, очистите фильтры. | |
| step.form.title | Форма создания или редактирования | Заполните рабочую форму | |
| step.form.body | Форма создания или редактирования | Заполните обязательные поля, проверьте значения и только затем нажмите основную кнопку действия в этой форме. | |
| step.data.title | Таблица, список или карточки | Проверьте результат | |
| step.data.body | Таблица, список или карточки | Просмотрите найденные записи и их статусы. Для продолжения откройте нужную строку или используйте действие рядом с ней. | |
| step.actions.title | Основные действия | Завершите текущий этап | |
| step.actions.body | Основные действия | Используйте основные кнопки этого блока после проверки данных. Опасные действия запрашивают отдельное подтверждение. | |

## Отдельные шаги сверки

Эти четыре формулировки сейчас применяются только на странице сверки с партнёром.

| ID | Шаг | Текущий текст | Новая редакция |
|---|---|---|---|
| reconciliation.choose.title | 1 | Выберите партнёра и период | |
| reconciliation.choose.body | 1 | Укажите партнёра, контакт и даты сверки. Для быстрого выбора периода можно нажать готовый вариант, затем проверьте заполненные даты. | |
| reconciliation.generate.title | 2 | Сформируйте сверку | |
| reconciliation.generate.body | 2 | Нажмите основную кнопку в этом блоке. Система сопоставит сообщения партнёра с внутренними кейсами за выбранный период. | |
| reconciliation.review.title | 3 | Проверьте результат и расхождения | |
| reconciliation.review.body | 3 | Сравните количества и строки с расхождениями. Для спорных записей укажите связь с внутренним кейсом и сохраните решение. | |
| reconciliation.finish.title | 4 | Зафиксируйте результат | |
| reconciliation.finish.body | 4 | После проверки обновите статус, сформируйте файл или сохраните ответ партнёра. Завершайте сверку только когда все расхождения разобраны. | |
